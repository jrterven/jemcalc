# Jem Calc · Flutter

Aplicación compartida para Android, iOS y web: editor matemático, teclado científico, escritura a mano, cámara, dictado, gráficas e historial local.

Consulta el [README principal](../README.md) para ver las capturas de cada modo, configurar el servidor y ejecutar la app. Las convenciones de compatibilidad están en [AGENTS.md](../AGENTS.md).

Desde este directorio:

```sh
flutter pub get
flutter analyze
flutter test
```

Las credenciales de proveedores pertenecen al backend y no deben incluirse en assets ni en compilaciones web.
